# Orbital Plane Visualization (Inclination Bands)

## Overview

The Orbital Plane Visualization feature allows users to visualize orbital planes and identify satellites that share similar orbital inclinations. This is particularly useful for analyzing satellite constellations (e.g., Starlink at ~53°), identifying orbital shells, and understanding spatial distribution patterns.

## Feature Description

The inclination band visualization renders orbital ground tracks on the 3D globe, highlighting satellites that fall within a specified inclination range. This enables operators to:

- **Identify Constellations**: Quickly spot satellite constellations that share similar orbital planes (e.g., Starlink, OneWeb)
- **Analyze Orbital Shells**: Visualize the distribution of satellites across different inclination bands
- **Understand Spatial Patterns**: See how satellites cluster in specific orbital planes

## Implementation Details

### Ground Track Rendering

- **Technology**: Uses deck.gl `PathLayer` to render orbital ground tracks as cyan arcs on the globe
- **Sampling**: Ground tracks are generated by sampling a representative satellite's orbit over one complete period
- **Resolution**: 240 points per orbit for smooth visualization while maintaining performance
- **Visual Style**: Cyan-colored paths with 70% opacity and 2px minimum width

### Interactive Controls

The feature provides three main controls in the right panel:

1. **Inclination Slider**
   - Range: 0-120 degrees
   - Step: 0.5 degrees
   - Default: 53° (Starlink shell)
   - Allows users to target specific orbital planes

2. **Tolerance Control**
   - Range: 0.5-10 degrees
   - Step: 0.5 degrees
   - Default: 2°
   - Controls the band width around the target inclination
   - **Smaller tolerance** = cleaner visualization with fewer matches (more precise)
   - **Larger tolerance** = more satellites included (broader analysis)

3. **Toggle Switch**
   - Enable/disable band visualization and highlighting
   - When enabled, shows ground track path and highlights matching satellites

### Satellite Highlighting

- Satellites within the selected inclination band are automatically highlighted
- **Visual Style**: Brighter cyan colors (`[0, 255, 255, 220]`) with increased radius
- **Size Increase**:
  - Debris: 30,000m → 40,000m
  - Active satellites: 70,000m → 90,000m
- Makes band satellites easy to identify on the globe

### Band Statistics

Real-time display of band metrics:

- **Number of Satellites**: Count of satellites matching the current inclination ± tolerance
- **Average Altitude**: Mean altitude of all satellites in the band
- **Current Range**: Displays the active inclination ± tolerance range

## Performance Optimizations

### Worker-Based Ground Track Generation

- **Offloading**: Ground track path generation (240 position calculations per orbit) is offloaded to a Web Worker
- **Worker Function**: `generateGroundTrackAsync` in `lib/satelliteWorker.ts`
- **Benefits**: Prevents UI blocking during heavy computations
- **Implementation**: Worker batches all position calculations and returns the complete path array

### Debounced Slider Inputs

- **Debounce Delay**: 300ms on both inclination and tolerance sliders
- **Purpose**: Prevents expensive recalculations during drag operations
- **User Experience**: UI remains responsive while heavy computations are deferred until the user stops adjusting
- **Implementation**: Uses `useEffect` with debounced state values

### Intelligent Caching

- **Cache Strategy**: Ground tracks are cached per `(inclination, tolerance)` key combination
- **Storage**: In-memory Map-based cache
- **Benefit**: Revisiting the same band settings instantly displays the cached track without recalculation
- **Cache Key**: Generated from rounded inclination and tolerance values

### Optimized Band Membership Computation

- **Data Structure**: Uses `Map`-based lookups (O(1)) for satellite ID matching
- **Computation**: Only recalculates when debounced values change
- **Memoization**: `useMemo` hook ensures band membership is only computed when necessary
- **Performance**: Efficient filtering of large satellite datasets

## Technical Stack

### Core Components

- **Worker Implementation**: `lib/workers/satellite.worker.ts` (Comlink-based)
- **Async Wrapper**: `lib/satelliteWorker.ts` (with caching and error handling)
- **UI Component**: `components/SatelliteGlobe.tsx`
- **Visualization**: deck.gl `PathLayer` + `ScatterplotLayer`

### Key Functions

- `generateGroundTrackAsync(entry, samples)`: Generates ground track path for a satellite
- `getBandSatelliteIds`: Computes which satellites match the current band criteria
- `bandTrack`: Memoized ground track path for the representative satellite

### Data Flow

1. User adjusts inclination/tolerance sliders
2. Debounced values update after 300ms
3. Band membership is recalculated (memoized)
4. Representative satellite is selected from the band
5. Ground track is generated (or retrieved from cache)
6. PathLayer renders the track on the globe
7. ScatterplotLayer highlights matching satellites

## Usage Examples

### Analyzing Starlink Constellation

1. Enable "Inclination Bands" toggle
2. Set inclination to 53°
3. Set tolerance to 2°
4. Observe the ground track and highlighted Starlink satellites

### Finding Polar Orbit Satellites

1. Enable "Inclination Bands" toggle
2. Set inclination to 90° (or near-polar)
3. Set tolerance to 5°
4. View all satellites in polar orbits

### Broad Shell Analysis

1. Enable "Inclination Bands" toggle
2. Set inclination to target shell (e.g., 98° for sun-synchronous)
3. Set tolerance to 10° for broader analysis
4. See all satellites in the general orbital region
