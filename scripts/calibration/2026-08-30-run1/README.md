# Stage 3 calibration — Run 1 (2026-08-30)

Reproducible artifacts backing the "Run 1" entry in
`docs/GEOMAGNETIC_CALIBRATION_LOG.md`. This directory is exploratory
analysis tooling, not part of the Next.js app's build — it requires
Python (pandas, numpy, scipy, statsmodels) and is run manually.

## Files

| File | What it is |
|---|---|
| `run1_queries.sql` | Exact SQL run against the production DB to produce `tle_raw.csv` |
| `tle_raw.csv` | Raw output of that query: 3,993 rows, 610 objects, perigee<350km, 2026-08-22–29, one row per (object, UTC day) |
| `dgd.txt` | Raw NOAA SWPC "Daily Geomagnetic Data" product, saved verbatim ([source](https://services.swpc.noaa.gov/text/daily-geomagnetic-indices.txt), issued 1230 UT 30 Aug 2026) |
| `convert_dgd_to_ap.ts` | Converts `dgd.txt`'s Estimated Planetary Kp column to ap using this repo's own production `normalizeKpClass()`/`kpToAp()` — not a re-implementation, so the analysis can't silently drift from what the app actually computes |
| `real_ap_series.csv` | Output of the above: 68 real three-hourly (intervalStart, kpClass, ap) rows, 2026-08-22–30 |
| `run1_analysis.py` | The original regression analysis (rate computation, altitude banding, OLS + robust + median regression, outlier investigation) |
| `addendum_lagged_activity.ts` | Addendum (2026-08-31): computes the actual production `computeRecencyWeightedActivity()` feature at every TLE epoch for four candidate decay constants (τ=6/12/18/24h) — the real production predictor, not Run 1's unweighted mean-ap |
| `tle_rates_with_lagged_activity.csv` | Output of the above |
| `addendum_analysis.py` | Addendum analysis: duration-filtered (≥12h), day-block-bootstrapped regression across all four τ — see `docs/GEOMAGNETIC_CALIBRATION_LOG.md`'s "Run 1 — Addendum" for why a block bootstrap replaces the original's OLS/robust/median approach |

## Reproducing

```bash
# From the repo root, regenerate real_ap_series.csv from dgd.txt:
npx tsx scripts/calibration/2026-08-30-run1/convert_dgd_to_ap.ts

# Then run the original Run 1 analysis (from this directory):
cd scripts/calibration/2026-08-30-run1
pip install pandas numpy scipy statsmodels
python3 run1_analysis.py

# For the addendum (from the repo root, then this directory):
npx tsx scripts/calibration/2026-08-30-run1/addendum_lagged_activity.ts
cd scripts/calibration/2026-08-30-run1
python3 addendum_analysis.py
```

`tle_raw.csv` can only be regenerated by re-running `run1_queries.sql`
against the production database — it isn't derivable from anything else
checked in here, which is why it's committed alongside the scripts rather
than treated as a build artifact.

See `docs/GEOMAGNETIC_CALIBRATION_LOG.md` for the narrative writeup,
conclusions, and what this run does and doesn't establish.
